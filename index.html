⏰ Hết giờ sạc pin

Cài đặt

Cần key để tìm kiếm và duyệt danh mục. Tạo miễn phí trong Google Cloud Console (bật “YouTube Data API v3”). Nên giới hạn key theo HTTP referrer của domain bạn. Key chỉ lưu trong trình duyệt này.

Không có key vẫn dùng được: dán link video/playlist vào ô tìm kiếm, hoặc mở mục “Gần đây”.
